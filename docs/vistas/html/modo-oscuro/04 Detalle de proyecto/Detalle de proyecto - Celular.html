Sobre el proyecto

Sistema web para controlar el inventario de una bodega universitaria. Registra entradas y salidas con un lector de códigos de barras desde el celular y genera reportes de existencias.

Desarrollado en la materia Bases de Datos II, con diseño del modelo relacional, API REST en Node.js y frontend en React.
