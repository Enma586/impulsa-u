# ImpulsaU · Vistas

- `index.html`: galería con todas las pantallas. Ábrelo en el navegador.
- `png/`: capturas a tamaño real, organizadas por modo y pantalla.
- `html/`: cada pantalla como HTML independiente (las tipografías se cargan desde Google Fonts, así que necesita internet).

Son maquetas de diseño: sirven de referencia visual para implementar los componentes de `packages/ui`, no son código de producción.
